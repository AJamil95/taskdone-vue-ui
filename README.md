# TaskDone Vue UI

## Acerca del proyecto

TaskDone Vue UI es una aplicación web construida con Vue.js 3 para la gestión de tareas personales. Incluye autenticación de usuarios, operaciones CRUD para tareas y una interfaz responsiva utilizando Vuetify.

## Cómo ejecutar

Después de clonar o descargar el proyecto:

1. Copia el archivo `.env.sample` a `.env` y configura las variables de entorno necesarias (ej. VITE_API_URL).
2. Instala las dependencias: `npm install`
3. Ejecuta el servidor de desarrollo: `npm run dev`

### Otros comandos útiles

- Verificar tipos, compilar y minificar para producción: `npm run build`
- Linting con ESLint: `npm run lint`
